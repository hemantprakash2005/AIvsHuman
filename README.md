# Detection of Human vs. AI Generated Texts 

A **Machine Learning based Command-Line Interface (CLI) Project** focused on the **classification of Human-written vs AI-generated texts**.  

This project was developed as the **main project during my internship at NIT Patna**.  
Multiple classification models were explored, evaluated, and compared to achieve the best performance.  

---

## 📂 Project Information  

- **Type:** Machine Learning   
- **Domain:** Natural Language Processing (NLP)  
- **Internship:** National Institute of Technology (NIT) Patna  
- **Primary Task:** Text Classification  
- **Goal:** Distinguish between **AI-generated** and **Human-written** text  

---

## 🔑 Key Features  

### 1️⃣ Multiple Model Implementations  
- Implemented and tested various **classification algorithms**, including:  
  - Traditional ML models (e.g., Logistic Regression, SVM, Random Forest).  
  - Deep learning and transformer-based models (where applicable).  

### 2️⃣ Text Preprocessing  
- Tokenization, stopword removal, lemmatization, and vectorization techniques such as:  
  - **TF-IDF**  
  - **Word2Vec / Embeddings**  

### 3️⃣ Comparative Evaluation  
- Evaluated models on standard metrics:  
  - **Precision, Recall, F1 Score, Accuracy**  
- Provided insights into which models perform best under different conditions.    

---

## 📊 System Workflow  

1. **Dataset preparation**: Human-written and AI-generated text samples collected.  
2. **Preprocessing**: Cleaning and transforming raw text into numerical vectors.  
3. **Model training**: Multiple classifiers trained on processed data.  
4. **Prediction**: Input text classified as **Human** or **AI-generated**.  
5. **Evaluation**: Performance compared across models using classification metrics.
